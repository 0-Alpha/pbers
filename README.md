# PBers — ポーランドボール チャンネル分析サイト

将来的に **pbers.com** として公開するための準備版サイト。日本のポーランドボール系
YouTubeチャンネルの登録者数を集計し、ランキング(棒グラフ)・シェア(円グラフ)で可視化する。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | サイト本体 |
| `assets/style.css` | スタイル(ベースカラー `#ac1c1c` / `#3c3c3c`、英数字は Space Grotesk) |
| `assets/app.js` | 棒グラフ・円グラフ・一覧の描画 |
| `assets/data.js` | 表示用データ(自動生成) |
| `channels.txt` | 集計対象チャンネルURL一覧 |
| `fetch.py` | 各チャンネルの登録者数・総再生数・投稿数を取得して `data.json` を出力 |
| `data.json` | 取得結果(最新スナップショット・毎回上書き) |
| `record.py` | `data.json` の当日分を `history.csv` に追記(蓄積) |
| `history.csv` | **日次の記録(上書きせず蓄積)**。列: date, id, name, subs, views, videos |
| `.github/workflows/daily.yml` | 毎日 JST 0時に自動取得・記録・push |

## データ更新の手順

```bash
python fetch.py      # channels.txt を読み、登録者数・総再生数・投稿数を data.json に保存
python record.py     # 当日分を history.csv に追記(既に当日分があればスキップ)
python gen_data.py   # data.json -> assets/data.js(固有色つきの表示用データ)
```

チャンネルを追加/削除する場合は `channels.txt` を編集してから上記を実行する。
チャンネル固有カラーは `gen_data.py` の `FIXED`(ID→hex)で管理。未指定は自動配色。
更新日(`data.js` の `PBERS_UPDATED`)は日本時間の当日を自動設定。

### ジャンル

`gen_data.py` の `GENRE`(ID→ジャンル名)でチャンネルを分類。未指定は
「ポーランドボーラー」。`GENRES` で設定パネルの並びと初期表示を定義
(通常のみ表示、「ポーランドボーラーのようなもの」「PBerer」は初期非表示)。
サイト右上の**歯車(設定)**でジャンルごとに表示/非表示を切替でき、円グラフ・棒グラフ・
一覧・成長・ニュース・合計すべてに反映される。

### 引退者の扱い

`gen_data.py` の `RETIRED`(チャンネルID集合)に入れたチャンネルは、
**データ取得・`history.csv` への記録は続けるが、グラフ・チャンネル一覧・ニュースには載せない**
(`data.js` と `news.js` から除外)。復帰時は `RETIRED` から外すだけでよい。

## 自動記録(GitHub Actions)

`.github/workflows/daily.yml` が **毎日 15:00 UTC(= JST 0時)** に上記3コマンドを実行し、
`history.csv` に1日1行ずつ蓄積して push する(`workflow_dispatch` で手動実行も可)。
`history.csv` は追記のみで**過去の記録は上書きしない**。同じ日付が既にあれば追記しない。

**日付の扱い**: JST 0時に取得した値はその**前日の最終値**とみなし、記録日・更新日・
ニュースの日付はすべて**前日**を基準にする(例: 8/21 0時取得 → 8/20 のデータ)。

## ニュース(直近7日)

`gen_data.py` が `history.csv` の前日→当日差分から2種類のニュースを生成する:

- 🎉 **マイルストーン突破**: 登録者1万・総再生1000万・投稿100 の刻みを跨いだとき。
- ⤴️ **追い越し**: あるチャンネルが前日は下位、当日は上位に入れ替わったとき
  (登録者数・総再生数・投稿数それぞれ)。「AがBを◯◯で追い越し」。

引退者は対象外。2日分以上の記録が貯まると出はじめる。

> Cloudflare Pages を GitHub 連携にしている場合、この毎日の push で自動再デプロイされる。
> Direct Upload の場合は別途アップロードが必要。

## 表示モード

ヒーローのトグルで **登録者数 / 総再生数** を切り替え可能。円グラフ・棒グラフ・
一覧・合計値がモードに応じて並び替え・再描画される。総再生数を非公開にしている
チャンネルは `—`(円グラフでは 0)として扱う。

また **「登録者10万人以上を除外」** フィルタで、大手を外して中小チャンネルだけを
見やすく表示できる(円グラフ・棒グラフ・一覧・合計すべてに反映)。

円グラフは **上位30チャンネル + 「その他」**(31位以下を1スライスに集約)で表示。
「その他」スライスにカーソルを乗せると合計値・チャンネル数・シェアが出る。
棒グラフ・一覧は全チャンネルを表示。棒グラフの見出しはモードに追従(登録者/総再生数ランキング)。

## タブ

ページ上部のタブで2画面を切替:

- **ダッシュボード**: 円グラフ・棒グラフ・ニュースなど。一覧は上位20 +「その他」
  (クリックでチャンネル一覧タブへ)。
- **成長**: `history.csv` から算出した直近7日(貯まっていなければその範囲)の
  **増減ランキング**。登録者/総再生数/投稿数を切替。増加は緑↑・減少は赤↓の縦向き矢印バー
  (`gen_data.py` が `assets/growth.js` を生成)。増減量の**偏差(zスコア)に応じて矢印の太さと
  矢じりの大きさが変わる**。**ズーム(＋/−)**で拡大縮小可能。履歴が2日分未満のときは非表示メッセージ。
  さらに下部に **界隈全体の推移(ステップ折れ線)** — 通常ジャンル(引退除く)の登録者/総再生数/投稿数の
  日別合計を、全履歴ぶんカクカクの折れ線で表示(上のトグルと連動)。
- **チャンネル一覧**: 登録者数の帯別(10万以上 / 5万〜10万 / 3万〜5万 / 2万〜3万 /
  1万〜2万 / 5000〜1万 / 5000未満)にグルーピングして全チャンネルを一覧表示。

## ローカルで確認

```bash
python -m http.server 8823
```

ブラウザで <http://127.0.0.1:8823/> を開く。`index.html` を直接開いてもデータは表示される
(データは `data.js` に埋め込み済みのため)。

## チャンネル個別ページ / シェア

- `gen_data.py` が各チャンネルの個別ページ `c/<channelId>/index.html` を生成
  (`assets/channel.js` が描画。登録者/総再生/投稿の推移ステップ折れ線・YouTubeリンク・
  シェアボタン)。SEO用に固有の title/description/canonical を付与し、`sitemap.xml` にも全ページを列挙。
- 一覧のカードは **本体クリック=個別ページ / 「YouTube」ボタン=YouTube** に分離。
- ヒーローと個別ページに **X / リンクコピー** のシェアボタン。
- 公開ドメインを変える場合は `gen_data.py` の `SITE` を変更(現状 `https://pbers.pages.dev`)。

## 取得ロジックの注意点

登録者数・総再生数は各チャンネルの **`/about` ページ**に含まれる
`aboutChannelViewModel` から取得している。ここには本人の
`subscriberCountText`(文字列)と `viewCountText`(総再生回数)が並んでおり、
本人の値であることが保証される。

- 登録者数: `"subscriberCountText":"チャンネル登録者数 …"`(**文字列形式**)。
  オブジェクト形式 `"subscriberCountText":{…}` はサイドバーの**関連チャンネル**の値なので拾わない。
- 総再生数: `"viewCountText":"…回視聴"`。
